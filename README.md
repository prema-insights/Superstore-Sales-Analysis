\# 🛒 Superstore Sales Analysis



\## 📌 Project Overview



This project presents an end-to-end Sales Data Analysis using the Superstore dataset. The analysis was performed using Excel, SQL Server (SSMS), Python, and Power BI to identify business insights, sales trends, customer behavior, and regional performance.



The project follows a complete Data Analytics workflow from data cleaning to interactive dashboard creation.



\---



\## 🎯 Project Objectives



\- Analyze overall sales performance.

\- Identify top-performing product categories and customer segments.

\- Compare sales across different regions.

\- Analyze monthly sales trends.

\- Discover top-selling products and customers.

\- Create an interactive Power BI dashboard for business decision-making.

\# 📊 Key Business Insights



\- Technology generated the highest overall revenue.

\- Consumer segment contributed the largest share of sales.

\- West region achieved the highest sales performance.

\- Sales reached their peak during November.

\- Top-selling products contributed significantly to overall revenue.
